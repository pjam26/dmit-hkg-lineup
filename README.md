## 香港 云：DMIT 香港机房的三条线路到底差在哪

DMIT 香港机房所有套餐用的硬件是同一套（AMD EPYC 平台、SSD 存储、KVM 虚拟化），区别只在网络出口。官方把香港线路分成三档：

- **Premium（Pro）**：电信走 CN2 GIA（AS4809），联通走 AS9929，移动走 CMI 直连。这是 DMIT 的旗舰线路，三网都有优化，到大陆延迟最低（华南 20–30ms，全国平均 40ms 左右），适合对国内访问质量要求高的场景。
- **Eyeball（EB）**：在 Tier 1 国际线路基础上叠加 CMIN2/CMI 优化，主要照顾移动用户，联通、电信是"尽力优化"。价格比 Pro 低 25%–40%，流量也更大，是性价比折中档。
- **Tier 1（T1）**：纯国际骨干（RETN 等），不对大陆做任何优化。好处是便宜、带宽大（10Gbps 端口），适合海外互访、做中转节点、或者用户根本不在大陆的场景。

一句话总结：**硬件一样，网络不一样**。你的用户在哪、预算多少、能不能接受晚高峰波动，决定了选哪条线。

## 香港 云：三个系列怎么选，先想清楚这四个问题

套餐表摆在那里，真正难选的是"我到底需要哪条线"。与其纠结参数，不如先回答几个实际问题。

**1. 你的用户/你自己在不在大陆？**

如果主要访问来源是大陆用户（建站、API、代理），Pro 的 CN2 GIA 是目前香港到大陆质量最稳的线路之一，晚高峰丢包率明显低于普通直连。第三方测评显示 Pro 全国平均延迟在 40–45ms，华南能到 20ms 出头。如果用户都在海外，T1 反而更合适——便宜、带宽大、不花冤枉钱买你用不上的大陆优化。

**2. 预算卡在哪个区间？**

Pro 起步 $39.90/月（TINY）已经是最便宜的 CN2 GIA 香港方案之一了，但 1 核 1G 500GB 流量只够跑轻量任务。EB.TINYv2 只要 $29.90/月，流量翻倍到 1000GB，代价是电信/联通没有 GIA 优化，移动用户反而体验更好。T1.WEE 年付 $36.9 起，是整个 DMIT 香港产品线里最便宜的入口，但你基本不能指望它给大陆用户用。

**3. 流量够不够用？**

Pro 的流量给得最保守（TINY 只有 500GB），因为 CN2 GIA 带宽成本高。EB 和 T1 的流量大方得多——EB.MICROv2 给 4000GB，T1.MICRO 直接 16000GB。如果你要跑视频中转、大文件分发、或者高流量代理，Pro 的高位套餐流量上限（GIANT 6000GB）可能不够，这时候 EB 或 T1 更现实。

**4. 对 IP 被墙的容忍度？**

DMIT 对 Premium 和 Eyeball 用户有免费换 IP 政策：不带 IP Care+ 服务的月付用户每 15 天可免费换一次，带 IP Care+ 每 7 天一次，其他情况 $5/次。T1 不保证 IP 全球可达，尤其大陆、俄罗斯等有网络审查的地区，换 IP 每次 $5、间隔 7 天。如果你买来是做敏感用途，Pro/EB 的换 IP 机制更友好。
